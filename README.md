# Summer Search proposal (web version)

Interactive proposal from Daybreak Collaborative and Team DSB for Summer Search's Messaging & Positioning RFP.

- Single static page: `index.html` plus `assets/`. No build step.
- Hosted with GitHub Pages from the `main` branch, root folder.
- Not indexed: the page carries `noindex, nofollow` and `robots.txt` disallows crawlers. Anyone with the link can still open it.
- Reference contact details are intentionally left off this version.
